# Как добавить ученика и создать ему учебный трек

Для Мурада. Всё делается в админке `/admin` (вход по коду из письма, пароля нет).
Время: 5–10 минут на ученика.

В этом руководстве **учебный трек** — это назначение ученику программы вместе с результатом теста уровня и личным планом.

**Порядок:** пригласить → ученик входит → провести тест уровня → заполнить карточку ученика → внести результат теста и создать трек → при необходимости поправить личный план → ученик нажимает «Начать».

---

## 1. Пригласить ученика

1. `/admin` → **Users**.
2. Над списком блок **Invite a student**: введите **Student email** и, если хотите, **Name (optional)** → **Invite**.
3. Ученику уходит письмо «Мурад пригласил тебя в трекер учёбы» со ссылкой на страницу входа. В письме нет кода и пароля, только ссылка.
4. Ученик появляется в списке Users с ролью `student` и датой приглашения.

Быстрая форма всегда отправляет первое письмо на русском с обращением на «ты». Если уже первое письмо должно быть на «вы» или на английском:

1. В **Users** нажмите **Create new**.
2. Заполните email и имя.
3. Обязательно выберите **Role = Student**.
4. До сохранения выберите **Locale** (`Русский` или `English`) и **Address form** (`Ты` или `Вы`).
5. Нажмите **Save** — письмо-приглашение отправится автоматически.

После приглашения ученик сам может менять язык и форму обращения в настройках. Если изменить их в админке уже после отправки, это повлияет на интерфейс и следующие письма с кодом, но не изменит уже отправленное приглашение.

Если админка пишет **This address already has an account**, такой email уже зарегистрирован. **Enter a valid email address** означает, что в адресе опечатка. Если отправить письмо не удалось, аккаунт ученика не создаётся.

## 2. Ученик входит

Ученик открывает ссылку из письма, вводит свой email, получает код на почту и попадает на `/study`.
Пока программы нет, он видит: «Мурад назначит программу после теста уровня».

Не пускает? Откройте его запись в Users → кнопка **Reset login limits** снимает лимиты кодов и попыток.

## 3. Профиль ученика (карточка)

Users → ученик. Заполните то, что ученик увидит в своей карточке на `/study`:

| Поле      | Что вписать                                                |
| --------- | ---------------------------------------------------------- |
| **Name**  | как к нему обращаться                                      |
| **Level** | A1–C2, его текущий уровень                                 |
| **Goal**  | цель, до 200 символов (например, «сдать IELTS 6.5 к лету») |

Фото ученик загружает сам в `/study/settings`. Строка «С нами с …» появится после создания трека: это дата теста уровня из следующего шага.

## 4. Внести результат теста и создать трек

В админке учебный трек называется **Назначение** (`Enrollment`). В одной записи хранятся результат теста, выбранная программа и статус обучения. Создавайте назначение со страницы ученика — так ученик подставится автоматически.

1. Users → нужный ученик → блок **Программы** → **Create new**. Ученик уже подставлен.
2. Блок **Тест уровня**:
   - **Тест** — «Мурад (CEFR)» (по умолчанию), IELTS, TOEFL iBT, Cambridge, Duolingo, PTE, EF SET или «Другой».
   - **Уровень CEFR** — вручную, автоматического пересчёта из баллов нет.
   - **Дата теста** — не в будущем.
   - **Балл** — появляется только у тестов с числовой шкалой. Допустимые диапазоны:

     | Тест      | Балл                                            |
     | --------- | ----------------------------------------------- |
     | IELTS     | 0–9, шаг 0,5                                    |
     | TOEFL iBT | 0–120, целое число                              |
     | Cambridge | 80–230 (+ **Экзамен**: KET, PET, FCE, CAE, CPE) |
     | Duolingo  | 10–160, шаг 5                                   |
     | PTE       | 10–90, целое число                              |
     | EF SET    | 0–100, целое число                              |

     Для **Мурад (CEFR)** балла нет. Для **Другой** укажите обязательное **Название теста** и, если нужно, **Результат** текстом до 40 символов.

   - **Заметка** — только для вас, ученик её не видит ни при каких условиях.
3. **Program** — выберите программу. В списке только опубликованные (статус `published`); черновики не предлагаются.
   Если уровень теста выше уровня программы, появится предупреждение — сохранить всё равно можно.
4. **Save**. Трек создан: статус станет `assigned`, ученику уйдёт письмо «Мурад назначил тебе программу A2 → B1», а в его личный план скопируется план программы по умолчанию.

Ограничения:

- у ученика одна «открытая» программа за раз (`assigned` / `active` / `paused`); вторая — ошибка «У ученика уже есть программа». Чтобы назначить другую, сначала завершите текущую (статус `finished`);
- сменить программу можно, пока ученик не нажал «Начать» (личный план при этом пересоздаётся);
- старт, дату старта и паузы отмечает сам ученик; Мурад вручную может только завершить программу.

Нет подходящей программы? Сначала создайте её: **Программы** (длительность в неделях, уровни «с/до», дни с занятиями) и **Банк заданий** → план по умолчанию. Подробно — в [руководстве по учебным программам](./testing-guide-study-programs.md), часть A.

## 5. Личный план (по желанию)

Users → ученик → **План ученика**: сетка «неделя × день». Каждое задание можно:

- заменить своим текстом (пометка «своё» вместо «из пула»);
- удалить или добавить (не больше 3 заданий в день, недели 1–52, дни 1–7).

План по умолчанию у других учеников и в самой программе при этом не меняется. Отметки и комментарии прошедших дней при правках сохраняются.

## 6. Ученик начинает

Ученик открывает `/study`, видит карточку программы (уровни, длительность, результат теста) и нажимает **Начать** → подтверждение → «Сегодня», день 1. Часовой пояс по умолчанию Алматы, он может сменить.

## 7. Смотреть прогресс

Откройте `/study/students` (ссылки в шапке нет, только по адресу): список учеников с днём программы, сделанными/пропущенными занятиями, минутами и последним учебным днём. Карточка ученика — сетка недель (только чтение) и его комментарии к дням.

## Если что-то не так

| Симптом                        | Что делать                                                                                                                              |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Письмо-приглашение не пришло   | проверьте спам и email в записи ученика; пришлите ученику ссылку `/login` вручную — в приглашении нет секретного кода                   |
| Письмо с кодом не пришло       | проверьте спам и email; затем запросите новый код, не превышая лимит попыток                                                            |
| Ученик не может войти          | Users → ученик → **Reset login limits**                                                                                                 |
| «У ученика уже есть программа» | завершите текущее назначение (статус `finished`)                                                                                        |
| Программы нет в списке         | она в статусе `draft` — опубликуйте                                                                                                     |
| Ошибка в баллах                | сверьтесь с таблицей диапазонов выше                                                                                                    |
| Удалить ученика                | Users → ученик → Delete; вместе с ним удаляются назначения, план, отметки, комментарии и фото. Подтвердите удаление только если уверены |
